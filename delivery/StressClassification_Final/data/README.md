# Data

Expected local input:

```text
data/DREAMER.mat
```

The large dataset is intentionally excluded from Git. DREAMER contains 23
participants, 18 audiovisual trials per participant, 14-channel EEG sampled at
128 Hz, two-channel ECG sampled at 256 Hz, and trial-level self-ratings for
valence, arousal, and dominance on a 1–5 scale.

Generated dataset manifests and split identifiers are tracked under
`data/processed/` when they contain metadata only. Signal arrays and caches
remain ignored.
