# Results

- `legacy/window_level_random_split/` contains the pre-audit outputs. These
  used 50% overlapping windows and random window-level splits and are retained
  only as historical evidence.
- Corrected runs are written to a unique experiment directory containing the
  resolved configuration, split IDs, environment metadata, metrics, per-class
  results, predictions, training history, model summary, logs, and figures.

No legacy result is described as a newly reproduced measurement.
